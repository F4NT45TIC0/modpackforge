    Configurações

    A Modrinth funciona sem chave. Para usar a CurseForge, solicite uma chave de API conforme as instruções da CurseForge. Depois cole a chave aqui e clique em Salvar. Ela vale para este app rodando no seu PC.

    Neste site, a chave é configurada pelo dono do projeto na Vercel: Settings → Environment Variables, nome CURSEFORGE_API_KEY, ambiente Production. Depois é preciso fazer Redeploy. A chave salva no app local não ativa a CurseForge neste site.

    A chave fica em , fora da pasta do app.
